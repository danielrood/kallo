01 — HOW THE TRIAL WORKS

Three facts. Then you are in.

STEP 1

Speak the three facts

Shop name, trade, existing number. Kallo listens in the browser with Web Speech and answers with the built-in voice. No account, no email, no diary booking.

STEP 2

It asks if something is missing

Any utterance is not enough. If a fact is blank, Kallo asks for it. It does not invent a shop name or a number.

STEP 3

Read, ring back, accept

Scan the summary, see the suggested callback window, and accept a quote as the customer would. This is a prototype, not a live line.

02 — WHAT THE INBOX HOLDS

Built for people who cannot pick up.

Urgency first

A lockout or a leaking stopcock is not the same as a hours question. Kallo sorts the list so the job that cannot wait is the one you see first.

A summary you can scan

Name, what is going on, and when they can take a return call. You are not replaying a voicemail in the van.

Quote accept

When a price is ready, the customer can accept it in the same thread. You see Accepted · demo on the card.

Keep the number you have

The trial asks for the number you already use so the inbox feels like your shop. This build does not forward or place calls.

03 — STRAIGHT ANSWERS

Before you tap the mic.

Does this call a real phone?

No. The trial is in-browser only. Speech stays with Web Speech and speechSynthesis. There is no live receptionist line in this prototype.

Why do I talk instead of filling a form?

The product is a voice receptionist. The trial starts the same way: speak the shop name, trade, and existing number. If a fact is missing, Kallo asks. There is no email field and no “book a walkthrough” path.

Are the customers real?

No. Every callback, summary, and quote is labelled Demo. Numbers use the UK 01632 / 07700 900 dummy ranges.

What if my browser cannot listen?

Chrome and Edge on HTTPS can use the microphone. If listening is blocked, type the same one sentence. Kallo still opens the inbox.

Kallo is a public prototype. It does not place or receive live phone calls, store passwords, or charge a card. Inbox rows marked Demo are sample jobs, not testimonials.
